# Project Summary

## One-line summary
SQL Server analysis of 120 years of Olympic history to identify medal leaders, athlete performance, first medals, cross-season achievements and consecutive Olympic victories.

## Recruiter pitch
Built a T-SQL Olympic data analysis project using athlete and event-level relational data. Used CTEs, joins, aggregation, ranking, STRING_AGG and window functions such as LEAD() to solve eight analytical business questions.

## Strong interview topics
- RANK vs ROW_NUMBER
- CTE design
- STRING_AGG for tie handling
- LEAD for consecutive Olympic cycles
- Conditional aggregation
- Joining master and event tables
